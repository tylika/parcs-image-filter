# Вхідні файли для показу через веб-інтерфейс PARCS

На сторінці **Add Job** (http://<IP майстра>:8080/add_job):
- Job name: будь-яка назва
- Solution file: `solution/solution.py`
- Input file: один із файлів цієї папки

| Файл | Що робить |
|---|---|
| input_sequential.txt | зображення 2048×2048, послідовна версія на майстрі (k=0) |
| input_2workers.txt | те саме, 2 воркери |
| input_4workers.txt | те саме, 4 воркери |

Після завершення на сторінці **Jobs** натисніть **Output**: там JSON із часом
(`t_total`, `t_compute_max`, `t_comm`) і контрольною сумою результату `md5_edges`.
Для всіх трьох задач `md5_edges` однаковий: паралельний результат збігається з послідовним.
